# LearnLoop — Figma UI Design

A learning-platform landing page designed in **Figma**. This repository showcases the LearnLoop interface design and its reusable visual components.

## Project Overview

LearnLoop is a landing-page design concept for a learning platform. The project files include SVG exports of the desktop landing page and UI components.

## Design Files

- `LearnLoop – Landing Page (Desktop 1440).svg` — desktop landing-page design.
- `Components.svg` — exported UI components.

> These are exported SVG design assets from Figma. This repository is a design showcase, not a live website or coded application.

## Preview

To preview the designs, open the SVG files in a web browser or import them into a design tool such as Figma.

## How to Use

1. Clone or download this repository.
2. Open the SVG file(s) in a browser to view the design.
3. Import the SVG files into Figma if you want to inspect or continue editing the design.

## Tools

- **Figma** — UI/UX design
- **SVG** — vector design exports
